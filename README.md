# Hi, I'm Immomoo

I build Web3 products with a focus on clean interfaces, encrypted user experiences, and practical decentralized infrastructure.

Right now, I am working on **Yora**, a time-locked encrypted capsule dApp for Aptos and Shelby. Yora lets users seal private messages or files, store encrypted blobs on Shelby, and make them available to a recipient wallet after a chosen unlock time.

## Current Focus

- Web3 product design and frontend engineering
- Aptos wallet-connected applications
- Shelby decentralized storage integrations
- Local-first encryption and privacy-focused UX
- Production-ready dApp polish for real community use

## Building

### Yora

A private capsule vault for messages and files.

- Encrypts payloads locally before storage
- Writes encrypted capsule blobs to Shelby
- Supports Shelbynet and Shelby Testnet routes
- Uses recipient wallet checks for unsealing
- Designed for a simple, premium Web3 experience
